# 小さな花屋の1ページのホームページ（HTML/CSS）

小さなお店向けの、1ページで完結するホームページ（LP）の見本です。
架空の花屋「花屋 つきくさ」を例に、**お店の魅力 → 商品 → 料金 → お店の情報 → アクセス → お問い合わせ**の順に、1ページで注文・相談まで進める構成にしています。

> 「花屋 つきくさ」は架空のお店です。住所・電話番号・料金はすべて見本用で、実在のお店・人物とは関係ありません。

## できること

- **HTMLとCSSだけ**で作っています（JavaScriptは使っていません）。レンタルサーバーやGitHub Pagesに置くだけで表示できます
- **スマホ・タブレット・パソコン**のどの幅でも、横にはみ出さずに読めます
  - スマホでは、カードや表が1列に並びかわり、ボタンが押しやすい大きさになります
- 上のメニューを押すと、ページ内の各セクションへ移動します（メニューは画面の上に残ります）
- 商品カード・料金表・営業時間・道順のイラストまで、小さなお店に必要な情報をひととおり入れています
- 写真がなくても形になるよう、イラストはSVGで描いています（本番では写真に差し替えられます）
- お問い合わせフォームは**見た目だけの見本**です。送信はされません

## 使い方

1. このフォルダ（`index.html` と `style.css`）をパソコンに保存します
2. `index.html` をダブルクリックすると、ブラウザで表示されます
3. 文章を変えるときは、`index.html` をメモ帳やVS Codeなどで開き、書き換えて保存します
   - 店名・住所・電話番号は「つきくさ」「〇〇県〇〇市」「000-0000-0000」を探して書き換えます
4. 色を変えるときは、`style.css` のいちばん上にある `--green`（緑）や `--rose`（ピンク）の値を変えます
5. 公開するときは、2つのファイルをサーバーの同じフォルダにアップロードします

### 本番で使うときに足すもの

- お問い合わせフォームの送信先（Googleフォーム、フォーム作成サービス、またはサーバーの送信プログラム）
- Googleマップへのリンク
- お店の写真（`<svg>` の部分を `<img src="写真.jpg" alt="説明">` に置きかえます）

## 動作環境

- 新しめのブラウザ（Chrome・Safari・Edge・Firefox）
- フォントは Google Fonts を読み込んでいます。インターネットにつながっていないときは、パソコンに入っている明朝体・ゴシック体で表示されます

## 動作確認したこと

- 幅375px（スマホ）・768px（タブレット）・1280px（パソコン）の3つの幅で表示し、横にはみ出す部分がないことを確認しました
- それぞれの幅で画面全体の画像を撮り、文字の重なり・切れ・ボタンの崩れがないことを目で確認しました
