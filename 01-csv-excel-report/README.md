# 売上CSVをExcelレポートに自動集計（Python）

毎月の売上を電卓や手作業で集計している方向けの、小さな自動化ツールです。
売上のCSVを1つ渡すだけで、**月別・商品別の集計表とグラフが入ったExcelファイル**ができあがります。

> 入っているデータは、見本用に作った**架空の花屋**の売上です。実在のお店・人物とは関係ありません。

## できること

- CSVを読み込んで、次の5つのシートを持つExcelファイルを作ります
  | シート | 中身 |
  |---|---|
  | 月別集計 | 月ごとの数量・売上と合計 |
  | 商品別集計 | 商品ごとの数量・売上・構成比（売上の多い順） |
  | 月×商品 | 月と商品のクロス表 |
  | グラフ | 月別の売上（棒グラフ）と、商品別の売上の推移（折れ線グラフ） |
  | 元データ | 読み込んだデータ一覧 |
- 金額は「1,234円」の形で表示し、見出しの色・罫線・合計行をそろえます
- 日付として読めない行があれば、知らせたうえで集計から外します
- 必要な列が足りないときは、どの列がないかを日本語で表示して止まります

## 使い方

1. Python 3.10以上を用意します（`python --version` で確認できます）
2. このフォルダで、必要なライブラリを入れます
   ```
   pip install -r requirements.txt
   ```
3. （見本データで試す場合）架空の売上CSVを作ります
   ```
   python make_sample.py
   ```
   `sample_data/sales.csv` に100行のデータができます
4. 集計してExcelを書き出します
   ```
   python report.py sample_data/sales.csv -o output/sales_report.xlsx
   ```
5. `output/sales_report.xlsx` をExcelで開くと、5つのシートが入っています

### 自分のCSVで使うとき

CSVには「日付」「商品名」「数量」「売上」の4つの列が必要です（「単価」など、ほかの列はあっても大丈夫です）。
列名が違うときは、次のように指定できます。

```
python report.py my_sales.csv -o report.xlsx --date-col 販売日 --item-col 品名 --qty-col 個数 --sales-col 金額
```

日付は `2026-07-01` や `2026/7/1` の形で書かれていれば読めます。文字コードはUTF-8（BOM付きでも可）にしてください。

## 動作環境

- Python 3.10以上（3.13で動作確認）
- pandas 2.0以上、openpyxl 3.1以上
- Windows・Mac・LinuxのどれでもOK。できたファイルはExcel・Googleスプレッドシート・LibreOfficeで開けます

## 動作確認したこと

- 見本データ（100行）で実行し、Excelの売上合計（1,085,480円）がCSVの合計と一致すること
- 3つの集計シートの合計行が、すべて同じ金額になること
- グラフが2つ入っていること

## 作業時間の目安

| 内容 | 目安 |
|---|---|
| このままの形で、お手元のCSVに合わせる（列名の変更など） | 1日 |
| 集計の切り口を増やす（店舗別・担当者別など） | 2〜3日 |
| 毎月決まったフォルダのCSVを自動で読み込む形にする | 3日 |
