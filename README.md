# ベリーの制作見本（ポートフォリオ）

小さなお店や個人の方の「毎日の作業を減らす」「お店を伝える」ための、小さな制作見本を3つ置いています。
どれも架空のデータ・架空のお店で作っており、実在のお店・人物とは関係ありません。

| 見本 | できること | 使った技術 |
|---|---|---|
| [01 売上CSVをExcelレポートに自動集計](01-csv-excel-report/) | 売上のCSVから、月別・商品別の集計表とグラフ入りのExcelを自動で作る | Python（pandas・openpyxl） |
| [02 期限が近いタスクを毎朝メールで通知](02-gas-deadline-notify/) | スプレッドシートの期限が3日以内の行を、毎朝1通のメールにまとめて送る | Google Apps Script |
| [03 小さな花屋の1ページのホームページ](03-flower-shop-lp/) | スマホでも見やすい、お店の紹介〜お問い合わせまでの1ページ | HTML・CSS |

花屋のホームページは、ブラウザでそのまま見られます：
https://rsb3lly.github.io/portfolio/03-flower-shop-lp/

それぞれのフォルダに、使い方を番号つきで書いた説明（README）を入れています。
