# 期限が近いタスクを毎朝メールで知らせる（Google Apps Script）

Googleスプレッドシートでタスクや納期を管理している方向けの、小さな自動化です。
毎朝7時台に、**期限が今日〜3日後で、まだ終わっていない行**を1通のメールにまとめて送ります。

> 見本のシートの中身は架空のものです。実在のお店・人物とは関係ありません。

## できること

- シートの「タスク名・担当・期限・状態」の4列を読みます（列の順番は自由です）
- 期限が**今日〜3日後**で、状態に「完了」「済」「済み」「done」が入っていない行だけを選びます
- 期限の近い順に並べ、1通のメールで送ります
  - 件名の例：`【期限が近いタスク】3件（今日までのものがあります）`
  - 本文は表になっていて、「今日まで」は赤、「あと1日」はオレンジで表示します
  - メールの最後に、シートを開くリンクが付きます
- 該当する行が0件の日は、メールを送りません
- 送り先のメールアドレスはコードに書かず、「スクリプト プロパティ」に登録します（コードを人に見せても、アドレスは漏れません）
- 料金はかかりません（Googleの無料の範囲で動きます）

## 使い方（設定の手順）

### 1. スプレッドシートを用意する

1. Googleドライブで「新規」→「Googleスプレッドシート」を選び、新しいシートを作ります
2. 画面下のシートのタブ（「シート1」）を右クリックし、「名前を変更」で **タスク** にします
3. 1行目に、見出しとして `タスク名` `担当` `期限` `状態` を入れます
   - 見本を使うときは、「ファイル」→「インポート」→「アップロード」で `sample_sheet.csv` を選び、「現在のシートを置換する」でインポートします
4. 「期限」の列を選び、「表示形式」→「数字」→「日付」にします

### 2. スクリプトを貼り付ける

5. スプレッドシートの上のメニューから「拡張機能」→「Apps Script」を開きます
6. 最初から入っている `function myFunction() {}` を消し、`Code.gs` の中身をすべて貼り付けます
7. 上の保存ボタン（フロッピーディスクの形）を押して保存します

### 3. 送り先のメールアドレスを登録する

8. 左の歯車のアイコン「プロジェクトの設定」を開きます
9. いちばん下の「スクリプト プロパティを追加」を押します
10. 「プロパティ」に `NOTIFY_EMAIL`、「値」に通知を受け取りたいメールアドレスを入れ、「スクリプト プロパティを保存」を押します

### 4. 一度動かして、許可を出す

11. 左の「<>」アイコン（エディタ）に戻り、上の関数の選択欄で `notifyDeadlines` を選んで「実行」を押します
12. 「承認が必要です」と出たら、「権限を確認」→ 自分のGoogleアカウントを選ぶ →「詳細」→「（プロジェクト名）に移動」→「許可」の順に進みます
    - 自分で作ったスクリプトなので、この警告が出るのはふつうです
13. 期限が今日〜3日後の行があれば、メールが届きます（0件のときは、下の「実行ログ」に「メールは送りません」と出ます）

### 5. 毎朝動くようにする

14. 関数の選択欄で `setupTrigger` を選んで「実行」を押します
15. 左の時計のアイコン「トリガー」を開き、`notifyDeadlines` が「日付ベースのタイマー」で1つだけ登録されていれば完了です
    - `setupTrigger` を何回実行しても、トリガーは1つにまとめられます

## 設定を変えたいとき

`Code.gs` の上のほうにある `CONFIG` を書き換えます。

| 項目 | 初めの値 | 意味 |
|---|---|---|
| `SHEET_NAME` | `'タスク'` | 読み込むシートの名前 |
| `DAYS_AHEAD` | `3` | 何日後までを「期限が近い」とするか |
| `DONE_WORDS` | `['完了','済','済み','done']` | 状態にこの言葉があれば通知しない |
| `NOTIFY_HOUR` | `7` | 毎朝何時台に送るか（変えたら `setupTrigger` をもう一度実行） |
| `COLUMNS` | タスク名・担当・期限・状態 | 見出しの名前が違うときに合わせる |

## うまくいかないとき

| 表示されること | 直し方 |
|---|---|
| `NOTIFY_EMAIL が登録されていません` | 手順8〜10をやり直してください |
| `シート「タスク」が見つかりません` | シートの名前を「タスク」にするか、`CONFIG.SHEET_NAME` を今の名前に変えてください |
| `見出しに「〇〇」の列がありません` | 1行目の見出しの文字を確かめてください（前後の空白は気にしなくて大丈夫です） |
| メールが来ない | 期限の列が日付になっているか、`2026/11/20` の形で書かれているかを確かめてください |

## 動作環境

- Googleアカウント（無料のアカウントで使えます）
- Googleスプレッドシート ＋ Google Apps Script
- 無料のアカウントでは、スクリプトから送れるメールは1日100通までです（このスクリプトは1日1通です）

## 動作確認したこと

Googleの外でも確かめられるよう、判定とメール作成の部分を、シートやメールに触らない関数に分けています。
`test/test.js` で、次のことを Node.js を使って確かめました（`node test/test.js` で実行できます）。

- 期限が今日・2日後・3日後の行は通知し、4日後・期限切れ・「完了」「対応済み」の行は通知しないこと
- `2026/11/22` のような文字で書かれた日付も読めること
- 期限が空の行は飛ばすこと
- 見出しの列が足りないときは、どの列がないかを日本語で知らせること
- タスク名に `<` や `&` が入っていても、メールの表がくずれないこと

※ Googleの上で実際にメールを送る確認は、手順4でお手元の環境で行ってください。
